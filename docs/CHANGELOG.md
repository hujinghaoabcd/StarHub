# 更新日志

## Unreleased · 2026-08-04

本轮项目从早期 Stars 管理器扩展为具备分类治理、可审核 AI 任务和安全迁移的本地优先工具。

### 仓库体验

- 详情区整合为单一摘要卡，包含仓库信息、GitHub、About、Pages、取消 Star、重点标记和关闭操作；按钮不再覆盖描述。
- 增加独立重点标记、重点筛选和优先排序。
- 全局筛选后排序再分页，支持每页 50–1000 项。
- 修复快速切换多个仓库时 README 请求与渲染累积导致的卡顿。
- 统一分页、按钮、分类颜色、长名称和侧栏排序显示。
- 登录页产品介绍全部接入中英文语言包，改为真实的本地优先、分类治理、人工审核 AI 和两阶段 README 流程。
- 删除登录页未启用 PWA、固定 18 分类、固定 10ms 搜索和“AI 自动写入”的过时宣传。

### 分类体系

- 增加“仅导入分类名称”，严格不导入项目关系。
- 增加通用正式分类注册表；不内置维护者个人体系。
- 支持稳定 ID、中英文名称、别名、说明、示例、排除项和层级。
- 导入前预览新增、更新、重命名、合并和冲突。
- 重命名保持 ID，合并迁移全部关系并去重，操作前快照且可撤销。
- 增加分类管理搜索、项目数量排序和空分类筛选。
- 数据库升级到 v8，备份格式升级到 v4。

### AI 分类

- API Key 改为 12 小时会话存储，自定义 endpoint 增加公网 HTTPS 与目标主机约束。
- 所有 AI/GitHub 任务请求支持 timeout 和真正取消。
- 模型只能返回正式注册表 category ID，不再自动创建分类。
- 增加结构化输出、Schema、仓库短 ID、重复/遗漏/未知 ID 与注册表版本验证。
- 增加持久任务、分段、暂停/恢复/取消、失败项重试和分页审核。
- 增加置信度、理由、人工分类修改、正确/错误评价、确认写入和撤销。
- 暂停时可提交当前有效草稿；提交后结束任务，剩余仓库以后新建任务。
- 增加低置信度与人工标错项目的 README 二阶段增强、缓存和差异审核。

### 部署、安全和文档

- 正式架构统一为 GitHub Pages 应用/文档 + Cloudflare Pages Functions OAuth API。
- Pages 部署加入构建提交标识、资源路径和公网冒烟验证。
- `npm run check` 覆盖 lint、类型、测试、OAuth、安全、CSP、审计与两类构建。
- 全面重写 README、安装、使用、分类、AI、配置、部署、排障、架构、项目状态与后续路线图。
- 新增截图规范与明确占位，旧截图不再作为新版功能证据。

### 已知限制

- 完整备份不包含 AI 任务、README 缓存和迁移快照。
- 完整备份导入与清空全部尚未清理三张 AI 历史表，列为下一批 P0。
- 未启用 PWA、跨设备同步和团队协作。
- AI 准确度尚无公开可复现的大型人工评测。

完整英文摘要见仓库根目录的 [README.en.md](https://github.com/hujinghaoabcd/StarHub/blob/main/README.en.md)，逐阶段完成状态见[项目状态](development/PROJECT_STATUS.md)。
